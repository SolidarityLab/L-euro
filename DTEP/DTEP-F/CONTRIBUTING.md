# Contributing to DTEP-F / Taler Corner5

Thank you for your interest in contributing to DTEP-F. The project is in specification phase. Contributions, reviews, and issue reports are welcome.

---

## Where to Contribute

**Protocol specification** — review of spec/ files for consistency, completeness, and alignment with Taler, Peppol, and ViDA standards. Issues and pull requests welcome.

**JSON Schema** — validation, edge cases, and alignment with EN 16931 semantic elements. Schema files are in schema/.

**Taler integration** — feedback from Taler Exchange implementers on the DD-18 extension, coin commitment lifecycle, and Contract Terms binding is particularly valuable.

**Peppol / ViDA alignment** — feedback from Peppol Access Point operators and national tax administration implementers on Corner 5 deployment scenarios.

**Analytical primitives** — mathematical review of the four primitives, threshold calibration methodology, and the temporal ontology formal properties.

---

## How to Contribute

1. Open an issue describing the problem or proposal
2. For specification changes: open a pull request with the modified spec file and a clear description of the change and its rationale
3. For JSON Schema changes: include a test case demonstrating the issue

---

## AI-Assisted Contributions

This project uses AI-assisted tools during specification and implementation. All AI-assisted contributions must be disclosed per commit following NLnet GenAI policy:

- Commit messages must identify AI-assisted contributions
- Model and version must be recorded
- Material prompts and unedited outputs must be referenced or attached per commit

See AI_usage_declaration.md for the declaration covering the initial specification phase.
